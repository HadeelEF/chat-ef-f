# ADR-0002 — مستودع GitHub مصدراً وحيداً للحقيقة (Repository as Single Source of Truth)

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-10-17 |
| Deciders | مالك المشروع |
| Related | NFR-MNT-02, ADR-0003 |

## Context

يعمل مالك المشروع من الهاتف فقط، ويتم التطوير عبر جلسات ذكاء اصطناعي مؤقتة (Claude Code، ومستقبلاً Codex).
المحادثات لا تُعتبر سجلاً موثوقاً، وأي جلسة جديدة تبدأ دون ذاكرة.

## Decision

1. مستودع `faenazi/ef-ai-workspace` (خاص) هو المرجع الوحيد لـ: الرؤية، المتطلبات، القرارات، المعايير، الإعدادات،
   تعريفات المساعدين والمهارات، الحالة، المخاطر، والتغييرات.
2. **GitHub Issues** هي سجل الأعمال (backlog) الوحيد؛ لا `BACKLOG.md` منافس.
3. **Pull Requests** هي الطريق الوحيد للتغيير؛ لا دمج دون موافقة مالك المشروع.
4. [project/CURRENT_STATE.md](../../../project/CURRENT_STATE.md) يسجل الحالة المتحقق منها مع الأدلة.
5. لا تُخزَّن في Git: الأسرار، بيانات الموظفين، قواعد بيانات المحادثات، أو مستندات المعرفة الحساسة — يُوثَّق موقعها ومالكها فقط.

## Rationale

يضمن الاستمرارية بين الجلسات، التتبع، المراجعة من الهاتف عبر GitHub، وقابلية التدقيق.

## Alternatives considered

| البديل | سبب عدم الاختيار |
|---|---|
| أدوات إدارة مشاريع خارجية (Jira/Notion) كمرجع | تشتت المرجع وصعوبة وصول الوكلاء إليه |
| ذاكرة جلسات الذكاء الاصطناعي | مؤقتة وغير قابلة للتدقيق |

## Consequences

- كل PR يحدّث التوثيق المتأثر و`CURRENT_STATE.md` عند تغيّر الحالة.
- الإعدادات المخزنة في قاعدة بيانات LibreChat (وكلاء، مهارات) تحتاج آلية مزامنة وكشف انحراف — انظر [ai/README.md](../../../ai/README.md).

## Verification

سيناريو الاستمرارية في [AGENTS.md](../../../AGENTS.md#session-start-protocol) — جلسة جديدة تحدد المهمة التالية من المستودع وGitHub فقط.
