# ADR-0005 — بنية حاويات قابلة للنقل (Portable Container Architecture)

## Context

البيئة الأولى VPS تجريبي، والإنتاج المستقبلي بنية تحتية سعودية معتمدة غير محددة بعد (OD-05).

## Decision

1. كل المكونات حاويات OCI بصور رسمية مثبتة بـ **tag + digest**.
2. الإعداد عبر متغيرات بيئة وملفات إعداد في المستودع؛ الأسرار تُحقن وقت التشغيل فقط.
3. البيانات الدائمة في volumes مسماة موثقة مع إجراءات نسخ واستعادة.
4. لا اعتماد على خدمات مُدارة خاصة بمزوّد سحابي محدد في المسار الأساسي.
5. أي خدمة خارجية (نماذج، embeddings، CDN) تُعامل كاعتمادية قابلة للاستبدال وتخضع لتقييم إقامة البيانات.

## Rationale

يسمح بالانتقال من VPS إلى بنية سعودية معتمدة (Compose أو Kubernetes) دون تغيير التطبيق.

## Alternatives considered

| البديل | سبب عدم الاختيار |
|---|---|
| خدمات PaaS مُدارة (MongoDB Atlas…) | ارتباط بمزوّد وإقامة بيانات غير مضمونة |
| تثبيت مباشر على الخادم دون حاويات | صعوبة النقل والترقية والتراجع |

## Consequences

- Artifacts في LibreChat تحمّل Sandpack bundler من CDN عام افتراضياً — يجب استضافته ذاتياً أو تعطيله قبل أي بيانات حقيقية
  (متحقق منه في توثيق LibreChat v0.8.8).
- خدمة RAG "lite" تتطلب embeddings عن بُعد افتراضياً — المزوّد يخضع لـ OD-01.

## Verification

M8: تمرين نقل (migration rehearsal) إلى بيئة مستهدفة ثانية باستخدام نفس الملفات.
