## Context

- طلب المالك ثمانية قوالب رسمية في «أوامر جاهزة» (Prompts في LibreChat)، يراها كل موظف ويستدعيها بـ «/»، كي يفهم الموظف فائدتها.
- طلب أيضاً أن يكون النشر للجميع للمسؤول فقط: المساعدون والأوامر الجاهزة والمهارات.
- ما في LibreChat v0.8.8 (من المصدر):
  - القالب مجموعة (`promptgroups`) لها اسم وسطر وصفي وتصنيف و`command`، ونص في `prompts`. لا مجلد نشر ولا seed للقوالب، بخلاف المهارات.
  - المشاركة بقوائم الصلاحيات (ACL): المالك `promptGroup_owner`، و«للجميع» = `promptGroup_viewer` لـ `PUBLIC`.
  - هكذا يمنح سكربت upstream `config/migrate-prompt-permissions.js` القالب العام صلاحيته.
  - قائمتا القوالب في الخادم (`getListPromptGroupsByAccess`) لا تعيدان `command` في v0.8.8؛ أصلحه upstream بعد v0.8.8.
  - فتظهر القوالب بأسمائها في قائمة «/» وتُصفّى بالاسم، ويظهر الاختصار (مثل `/letter`) بعد ترقية LibreChat (#62)؛ الاختصار محفوظ.
  - `interface.prompts.public` يُكتب لدوري USER وADMIN معاً عند كل إقلاع. حذفه مع بقاء `share` يعطي كل دور قيمته
    الافتراضية: false للموظف وtrue للمسؤول (`packages/api/src/app/permissions.ts`). وكذلك المساعدون والمهارات.

## Decision

1. **المصدر:** القوالب في [`ai/prompts/ef-templates.json`](../../../ai/prompts/ef-templates.json): الاسم والأمر والتصنيف والسطر والنص بحقوله
   `{{...}}`، وتُراجع وتُدمج عبر PR. نصوص كتابة عامة فقط: لا بيانات للصندوق ولا سياسة أعمال.
2. **الإنشاء:** سكربت [`infrastructure/common/prompts-seed.js`](../../../infrastructure/common/prompts-seed.js) داخل حاوية LibreChat
   (`/app/config/efaiw-prompts-seed.js`)، يعمل في الخلفية عند كل إقلاع:
   - ينتظر أدوار الصلاحيات التي ينشئها الخادم، وأول حساب ADMIN (حتى ساعة، كل 20 ثانية)، ثم ينتهي.
   - ينشئ كل قالب مجموعةً يملكها أول مسؤول، باسم المؤلف «صندوق البيئة»، ويمنحها `promptGroup_viewer` لـ `PUBLIC`.
   - **مرة واحدة فقط:** علامة لكل قالب في مجموعة `efaiw_seeds`. لا يكتب فوق تعديل المسؤول، ولا يعيد قالباً حذفه المسؤول.
     وإن وُجدت مجموعة بالأمر نفسه تُترك كما هي.
   - يحمّل نماذج LibreChat دون إضافة البحث (يحذف `MEILI_HOST` و`MEILI_MASTER_KEY` من عمليته فقط): الإضافة تنشئ فهارس
     Meilisearch وتضبطها، فلو سبقت الخادم إلى فهرس فارغ (فقدان volume البحث) لتخطّى الخادم إعادة بنائه (M55).
3. **التشغيل:**
   - Railway: `librechat-start.sh` يشغّله في الخلفية بالمستخدم `node` مع تشغيل الخادم. الصورة تنسخ `ai/prompts/` والسكربت، وهما ضمن watch paths.
   - Compose: ربط الملفين للقراءة فقط، و`command` للخدمة يشغّله ثم `npm run backend` (أمر الصورة نفسه).
4. **النشر للجميع للمسؤول فقط:** `agents` و`prompts` و`skills` في `librechat.yaml` بـ `share: true` دون `public`.
   الموظف يشارك مع زملاء يختارهم، والمسؤول ينشر للجميع (مثل الأوامر الرسمية).
5. **الروابط المشتركة:** تبقى للمسجّلين فقط (`ALLOW_SHARED_LINKS_PUBLIC=false`)؛ «للجميع» فيها يعني أي موظف مسجّل.

## Rationale

- مصدر واحد في Git بنفس الملف في البيئات الثلاث (ADR-0008)، دون سر ولا حساب خدمة ولا اتصال خارجي.
- يستخدم دوال LibreChat نفسها (`createPromptGroup`، `grantPermission`)، فالقالب مثل قالب أنشأه مسؤول من الواجهة: يعدّله
  ويحذفه من الواجهة، ويرى الموظف «للجميع» دون صلاحية تعديل.
- «مرة واحدة» تحترم قرار المسؤول بعد الإنشاء، ولا تعيد النشر مع كل إقلاع.

## Alternatives considered

| البديل | لماذا لم يُختر |
|---|---|
| إنشاء القوالب يدوياً من الواجهة في كل بيئة | يدوي، ويتكرر في كل بيئة، ولا مراجعة له في Git |
| سكربت عبر API (`POST /api/prompts` ثم مشاركة) | يحتاج كلمة مرور مسؤول سراً في السكربت أو في البيئة |
| مزامنة دائمة تكتب فوق التعديلات عند كل إقلاع | تمحو تعديل المسؤول وتعيد ما حذفه؛ القوالب أمثلة يعدّلها المسؤول لا إعداد ثابت |
| `public: false` كما كان | يمنع المسؤول أيضاً من النشر للجميع، فلا تصل القوالب الرسمية للموظفين |

## Consequences

- القوالب تظهر بعد أول إقلاع يوجد فيه حساب مسؤول. في قاعدة جديدة: بعد إنشاء أول حساب، خلال 20 ثانية.
- تعديل نص قالب في المستودع لا يغيّر قالباً أُنشئ من قبل: يعدّله المسؤول من الواجهة. القالب الجديد في الملف يُنشأ في الإقلاع التالي.
- لإعادة إنشاء قالب حذفه المسؤول: احذف علامته من `efaiw_seeds` (`prompt:<command>`) وأعد التشغيل.
- كل تعديل في `ai/prompts/` أو في السكربت ينشر `librechat` على Railway `dev` فور الدمج (ADR-0010).
- فحوص `mock_chat.py`: M87–M90 (القوالب للجميع، للقراءة فقط عند الموظف، النشر للمسؤول فقط، لا تكرار بعد إعادة التشغيل)، وM22 لصلاحيات الدورين.
