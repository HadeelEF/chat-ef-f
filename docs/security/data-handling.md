## 1. التصنيف المؤقت للمشروع

> هذه الفئات **مؤقتة للتطوير فقط** وتُستبدل بسياسة التصنيف الرسمية للصندوق عند توفرها.

| الفئة | أمثلة | مسموح في Git | مسموح في بيئة العرض | مسموح لمزوّد نماذج خارجي |
|---|---|---|---|---|
| P0 — عام/اصطناعي | بيانات اصطناعية، توثيق، إعدادات بلا أسرار | نعم | نعم | نعم (مزوّد معتمد للعرض) |
| P1 — داخلي | وثائق داخلية غير حساسة | لا (يُوثّق الموقع فقط) | **لا** حتى اعتماد البنية | **لا** حتى الاعتماد |
| P2 — سري/حساس | بيانات موظفين، عقود، مالية، كراسات RFP حقيقية | **لا** | **لا** | **لا** |
| S — أسرار | مفاتيح API، كلمات مرور، شهادات | **لا أبداً** | `.env` محلي غير متتبع، متغيرات Railway، مخزن أسرار مؤسسي | — |

## 2. قواعد إلزامية

1. **بيانات اصطناعية فقط** في التطوير والعرض (NFR-PRIV-01).
2. لا رفع لبيانات P1/P2 إلى Railway (خارج المملكة؛ ADR-0008)، أو أي خادم شخصي، أو واجهات نماذج خارجية.
   Railway وWindows المحلي بيئتا P0 فقط؛ Ubuntu في الموقع P0 حتى اعتماد بوابات M6/M8.
3. البيانات الاصطناعية توسم بوضوح (مثلاً بادئة `SYNTHETIC —` في العنوان أو اسم الملف).
4. أي بيانات اختبار تُخزّن في `tests/fixtures/` أو `ai/knowledge/synthetic/` (عند إنشائها) وتكون P0 فقط.

## 3. أين تُخزّن البيانات خارج Git

| النوع | الموقع المعتمد | المالك | دورة الحياة |
|---|---|---|---|
| أسرار وقت التشغيل | `.env` (Windows/Ubuntu، git-ignored) / متغيرات Railway (قابلة للختم) | مالك المشروع (عرض) / فريق التقنية (إنتاج) | تدوير عند الاشتباه وقبل الإنتاج |

| مستندات المعرفة الحقيقية | **غير محدد** — بنية معتمدة فقط | مالكو المساعدين (TBD) | TBD |
